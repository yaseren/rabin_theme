Place your licensed local Yekan font files in this directory:

- Yekan-Regular.woff2
- Yekan-Medium.woff2
- Yekan-Bold.woff2

The theme does not bundle font binaries. Make sure your font license permits
self-hosting and redistribution inside your private/public application repository.
If your font provider uses different file names or weights, update the @font-face
rules in `../css/rabin_theme.css` accordingly.
